Banc de mesure — détection open-vocabulary

Ce test décide si NOVA-7 peut reposer sur un modèle capable de reconnaître n'importe quel objet plutôt que 80 classes figées. Il mesure ce qu'aucune documentation ne peut prédire : le temps de téléchargement, la latence d'inférence sur votre machine, et la justesse sur vos objets. Aucune image ne quitte votre ordinateur.

2 · Chargement du modèle

Le modèle est téléchargé depuis le CDN de HuggingFace puis mis en cache par le navigateur. Le premier chargement est lent, les suivants immédiats — les deux chiffres comptent.

3 · Latence d'inférence

Mesurée sur votre webcam. Le seuil qui compte : sous 300 ms le scan paraît instantané, au-delà d'une seconde il faut repenser l'ergonomie du scanner.

Ces étiquettes sont libres : le modèle cherche ce que vous écrivez. C'est précisément ce que COCO-SSD ne sait pas faire.

4 · Verdict

En attente de mesure.
